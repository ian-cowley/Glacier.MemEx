Universal episodic memory engine for .NET 10 uniting `Glacier.Chrono`, `Glacier.DocTree`, `Glacier.Vector`, `Glacier.Graph` (HippoRAG Personalized PageRank), `Glacier.Quant`, and `Glacier.Bundle` with ACT-R power-law temporal decay and 0/1 knapsack prompt packing.

## Installation

```bash
dotnet add package Glacier.MemEx
```
